Reports a background-thread entry point (a Task.Backgroundable override, a task passed to Application#executeOnPooledThread, to the AppExecutorUtil pooled executor, or to BackgroundTaskUtil#executeOnPooledThread) that can reach a blocking, non-cancellable read action, directly or through a project method.

A blocking read action on a background thread makes pending write actions wait, which can freeze the editor. Two tiers are reported: ReadAction.compute()/run()/computeCancellable(), which are deprecated, and Application#runReadAction(...), whose documentation advises against this use. A non-blocking read action (ReadAction.nonBlocking(...)) yields to writes and follows cancellation.
